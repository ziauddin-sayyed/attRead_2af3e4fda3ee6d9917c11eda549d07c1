Element — position & size

Click any element on the card to select it (photo, signature, name, details, “Principal”).
Line-height controls spacing between lines inside the selected element. Most useful for details block.
Applies to name, details and Principal only. “Bold” makes values bold; details keys stay 800.
Choose Circle (50% radius) or Rectangle (6px radius). Border renders around photo; matches card background hole.
Drag directly on card to move. Hold Shift while dragging for finer control.

Layers — front / back

Click a layer to select. “Front” puts it above all, “Back” below all. Z values are editable above.

Tips

• Only one card is rendered at a time (no bulk).
• Use Step 1 to change background, Step 2 to pick the row with max text, Step 3 to map {column}.jpg.
• Photos are downscaled to 480p max before display for speed.
• Print prints only the single card (A4 landscape friendly — duplicate via copy-paste if needed).
